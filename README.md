# SportGest Alzira

Herramienta de horarios de SportGest (Alzira), como PWA con sincronización en la nube.

- **Login** (usuario/contraseña) y **sincronización** vía Supabase.
- Los **datos reales** (planilla, monitores) viven en la nube protegida por login.
  Los archivos publicados **no contienen datos personales** (`data.js` va vacío).
- Módulos: planilla semanal/periodo, jornada por trabajador, cálculo de nómina,
  importar/exportar JSON y Excel.

Publicado con GitHub Pages. Para configurarlo desde cero, ver la guía interna del proyecto.
